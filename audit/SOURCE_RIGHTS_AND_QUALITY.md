# Arabic Document Atlas: source rights and quality boundaries

Research/acquisition audit dated 2026-10-15. Source assertions are recorded as assertions; this document does not turn public-domain material into CC0 or certify copyright status in every jurisdiction.

## Arabic Wikisource proofread tier

The live siteinfo API identifies Arabic Wikisource text licensing as **CC BY-SA 4.0**. The ProofreadPage API identifies Page namespace 104, Index namespace 106, and quality levels 3 (proofread) and 4 (validated). A category-info probe reported 23,910 and 3,497 ordinary category pages respectively, before namespace/content/scan-pair checks. Those counts are an acquisition starting point, not a published usable-pair total.

Each record retains source page ID, revision ID/time/SHA1, exact original revision wikitext, a mechanically isolated transclusion body, page/history/permalink attribution URLs, API response hash, and observed source quality. Acquisition accepts the source quality only when the stored pagequality tag, proofread property, and pageprops quality agree. This is a rolling API snapshot, not a whole-wiki transaction. De-duplicate repeated source revisions and explicitly record category movements.

**Text redistribution rule:** preserve source attribution and imported-source notices, link the license, describe transformations, and distribute adapted community text under CC BY-SA 4.0. Underlying public-domain works retain that status; the license notice describes the Wikisource community text/derivative representation, not a claim to own the historical text. Source content and body wikitext remain available so consumers can audit mechanical extraction. Wikitext templates can encode poetry, tables, and footnotes: blindly deleting every template destroys text. Any rendered/plain-text field must identify its extraction method and retain the raw body.

**Quality rule:** publish `source_community_proofread` and `source_community_validated` separately. The source describes proofread as one contributor and validated as two contributors; Bayanat did not commission or independently verify those people or every transcription. Neither tier is error-free gold. Source newlines are not image line annotations. This source provides a page-level scan/text relationship, not verified line/region boxes or reading-order polygons.

**Scan rule:** text licensing is not scan licensing. Retrieve each referenced file's repository, exact SHA1/version timestamp, original URL, dimensions/page count, description URL, author/credit/license/usage/restriction metadata and exact file-description revision from Commons or local Arabic Wikisource. Retain missing/unknown values. Do not assume a PDF first-page width/height describes every page. Source image metadata is community supplied. Public images require a recognized compatible file license or recorded public-domain rationale, no active contradictory restrictions/deletion/copyright flags, retained credits and file-specific license; unknown/restrictive evidence stays metadata-only. Recheck underlying edition/translator/editor issues where apparent. No images are downloaded by the Wikisource acquisition module.

Primary sources: [live rights and namespaces API](https://ar.wikisource.org/w/api.php?action=query&format=json&meta=siteinfo%7Cproofreadinfo&siprop=rightsinfo%7Cnamespaces), [Wikimedia Terms, section 7](https://foundation.wikimedia.org/wiki/Policy:Terms_of_Use#7._Licensing_of_Content), [source page-status definitions](https://en.wikisource.org/wiki/Help:Page_status), [ProofreadPage documentation](https://www.mediawiki.org/wiki/Extension:ProofreadPage), [Commons reuse requirements](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia), [API etiquette](https://www.mediawiki.org/wiki/API:Etiquette).

## NYU Arabic Collections Online

ACO's official about page says the participating institutions selected out-of-copyright books and that NYU researched publication-country requirements and believes the displayed materials are public domain. Manifests can carry the institutional assertion in `requiredStatement` while `rights` is absent. Record both facts exactly, together with provider and manifest hashes; a missing machine-readable license is not a CC0 dedication. An institutional public-domain assertion is useful provenance and an acquisition basis, but does not eliminate conflicting edition/contributor evidence.

The first release should prioritize editions with an unambiguous publication year at or before 1930, the institutional assertion present, no contradictory rights URI, and no apparent later translation/editorial addition. This cutoff is a conservative project triage rule, **not a worldwide legal test**. Unknown/ambiguous dates, modern editions, or contradictory rights remain inventory-only until reviewed. Store contributor names/dates when available and distinguish verified facts from missing life dates. Do not claim all 17,698 volumes cleared merely because they are in the catalog. Credit the supplying institution and link original book/manifest/takedown policy. Preserve any item-specific terms. Public-domain images need no invented new license; Bayanat annotations/code can have their own clearly scoped license.

Primary sources: [ACO about and copyright guidelines](https://web2.dlib.nyu.edu/about), [official IIIF/API documentation](https://sites.dlib.nyu.edu/viewer/api/v1/image), [example manifest with requiredStatement](https://sites.dlib.nyu.edu/viewer/api/presentation/books/nyu_aco000511/manifest.json).

## DOAJ modern born-digital supplementary route

DOAJ metadata is CC0; that does not license publisher PDFs. The saved journal census identifies 295 Arabic-accepting journals whose parsed journal license entries include unrestricted CC BY or CC BY-SA, but multilingual journal membership does not prove an individual paper is Arabic. A starter PDF set must record the paper's own explicit license/date, actual Arabic text, publication metadata, publisher URL, PDF hash and transformation details; omit NC/ND/own-license/unknown files from a commercially reusable derivative tier. Journal metadata is discovery evidence, not final per-paper permission. Keep this tier separate from community-proofread historical scans.

Primary sources: [DOAJ terms](https://doaj.org/terms/), [public data access](https://doaj.org/docs/public-data-dump/). Local metadata census: `research/next-massive-arabic-source-audit/doaj-journal-license-probe.json`.
