# Arabic Document Atlas explorer

A static, English-default viewer of actual examples from the pinned Bayanat
Arabic Document Atlas release. It runs in the visitor's browser with no paid
server or GPU. The visible examples are a small, deliberately selected subset;
the complete versioned dataset is linked from the application.

Source image rights and attribution remain component-specific. See the dataset's
DATA_LICENSE.md and each page's original institution/source links. Code is
Apache-2.0. Machine word guides and line order are approximate, not human gold.
