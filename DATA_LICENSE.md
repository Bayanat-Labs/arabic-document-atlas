# Component-specific rights

This release has no blanket CC0 dedication and no universal scan-image license.

## ACO page images and source text

The Arabic Collections Online institutions state that they believe the displayed
materials are in the public domain. Bayanat preserves their exact statements,
source links, supplying institutions, edition metadata and manifest hashes.
The image tier prioritizes editions with an unambiguous publication year at or
before 1930 and no contrary rights evidence in the retrieved manifest. This is a
project triage policy, not independent worldwide copyright clearance. Underlying
works retain their existing rights. See each row's `source_rights` fields and
[the source's copyright explanation](https://aco.dlib.nyu.edu/about).

## Bayanat machine annotations and documentation

Bayanat's original annotation representation, quality reports and documentation
are offered under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
Attribute Bayanat Labs and the named original source institution; identify
changes. This license does not replace rights in the underlying scan or text.

## Arabic Wikisource community text

The separate `community_text` configuration contains adapted community text,
original wikitext and source metadata. Text is redistributed under
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/), with revision,
history and attribution links in each row. Retain those links and imported
notices, indicate changes and apply the required share-alike terms to adapted
text. Underlying public-domain works retain that status. Referenced scan files
have separate file-specific rights; this configuration does not contain their
image bytes and the text license does not license those images.

## Code and dependencies

Original pipeline and explorer code are Apache-2.0, as set out in `LICENSE`.
Dependencies retain their own licenses. Apple Vision is a proprietary system
dependency, not an open-source OCR model distributed by Bayanat.

For a correction or rights concern, contact hello@bayanatlabs.com with the page
identifier and original source URL. The project links to the original source's
rights and takedown procedures; it does not imply institutional endorsement.
